# Public Repository Guide

This repository is a learner-facing evidence system for examining the records connected to *FUN AGAIN: An Inquiry Through Election Records*.

## What is included

- A governed claim-to-source workbook
- Four organized source-document collections
- Corpus provenance and acquisition boundaries
- SHA-256 integrity records
- A transparent review method
- A pathway for future review and revision

## What is not included

The full book manuscript is not included. The book remains a separate publication. This repository provides the evidence path so readers can inspect the underlying public records without purchasing the book.

## A practical review path

1. Choose a collection in `06_Source_Corpus`.
2. Open a source PDF and identify the exact page being examined.
3. Use the governance workbook to locate the connected Claim ID and governed wording.
4. Record what the page visibly establishes.
5. Record what it does not establish.
6. Separate direct evidence from inference and interpretation.
7. Preserve contradictions, redactions, missing dependencies, and unresolved questions.
8. Revise visibly when stronger evidence changes the understanding.

## Using AI responsibly

AI can help prepare possibilities: locating terms, comparing records, summarizing long documents, or generating questions. AI output is not the evidence. Return to the source page before making a publication-level claim.

**Evidence gives the exploration integrity. Agency gives learners freedom to explore. Human judgment remains central.**
