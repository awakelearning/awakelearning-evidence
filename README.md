# Awake Learning Election Evidence Repository

This public repository supports *FUN AGAIN: An Inquiry Through Election Records* by making the underlying documentary record available for independent examination.

**The book manuscript is not included in this repository.** The book and the evidence repository serve different roles: the book presents the inquiry and narrative; the repository preserves the documentary pathway so learners can examine the records for themselves.

## Begin here

1. Read the [Public Repository Guide](01_Public_Repository_Guide/README.md).
2. Open the [Source Corpus](06_Source_Corpus/) and choose one of the four review collections.
3. Use the [Governance Workbook](02_Governance_Workbook/) to move from a governed claim to the cited source and page.
4. Review the [Corpus Provenance](03_Corpus_Provenance/README.md) and [Audit Trail](07_Audit_Trail/) to understand acquisition, preservation, boundaries, and file integrity.
5. Use the [Reviewer Guide](04_Reviewer_Guide/README.md) to document findings, limits, alternative explanations, and unresolved uncertainty.

## Corpus map

- **Voting Systems:** 8 PDF placements, 37 review pages
- **China and Voter Data:** 23 PDF placements, 167 review pages
- **Michigan Registrations:** 25 PDF placements, 53 review pages
- **Noncitizens and Database Threats:** 2 PDF placements, 12 review pages

**Total:** 58 PDF placements, 269 review pages, 55 unique PDFs, and 3 intentional cross-folder repeats.

Repeated placement improves navigation when one record supports more than one review path. It does not multiply the evidence.

## Review principles

- Separate observation, evidence, inference, interpretation, and unresolved uncertainty.
- Return to the rendered source page when extracted text, OCR, redaction, or formatting creates ambiguity.
- State what the evidence supports and what it does not support.
- Preserve contrary, contextual, and superseding evidence.
- Document meaningful revisions rather than silently replacing earlier conclusions.

AI may assist with navigation, comparison, summarization, and question generation. Human judgment remains central, and publication-level conclusions must return to the source record.

The source materials are free to examine. No purchase is required.

**Documentation supports conversation. Transparency builds trust. Inquiry remains open because learning never truly ends.**
